# YT2MP3 บน Android (Termux)

## A. ติดตั้งครั้งเดียว

1. ติดตั้ง 2 แอปนี้จาก **F-Droid** (https://f-droid.org) — ต้องมาจากแหล่งเดียวกัน ห้ามปนกับ Play Store
   - **Termux**
   - **Termux:Widget**
2. ย้ายไฟล์ `yt2mp3-android.zip` เข้ามือถือ ให้อยู่ในโฟลเดอร์ **Download**
3. เปิด Termux แล้วพิมพ์ทีละบรรทัด:
   ```
   termux-setup-storage
   ```
   (กด "อนุญาต" ที่หน้าต่างขอสิทธิ์)
   ```
   pkg install -y unzip
   unzip ~/storage/downloads/yt2mp3-android.zip -d ~
   bash ~/yt2mp3/setup.sh
   ```
   ถ้ามีคำถามระหว่างอัปเดตแพ็กเกจ ให้กด Enter หรือพิมพ์ `y` รอจนขึ้นว่า "เสร็จแล้ว"

## B. สร้างไอคอนบนหน้าจอหลัก

1. กดค้างที่หน้าจอหลัก → **วิดเจ็ต (Widgets)** → **Termux:Widget**
2. เลือกแบบ **Shortcut** (ไอคอน 1 ช่อง) วางบนหน้าจอ
3. จะมีรายการให้เลือก → เลือก **YT2MP3** (ถ้าไม่เห็น ให้เปิด Termux หนึ่งครั้งแล้วลองใหม่)
4. (ทางเลือก) ทำอีกอันสำหรับ **YT2MP3-stop** ไว้ปิดเซิร์ฟเวอร์

## C. ตั้งค่า Android ให้ไม่ปิดแอปเอง (สำคัญบน OPPO/ColorOS)

ชื่อเมนูอาจต่างเล็กน้อยตามเวอร์ชัน:
1. **ตั้งค่า → แอป → จัดการแอป → Termux → การใช้แบตเตอรี่** → เลือก "ไม่จำกัด / อนุญาตทำงานเบื้องหลัง" และเปิด "เปิดอัตโนมัติ" ถ้ามี
2. **ตั้งค่า → แอป → Termux → แสดงทับแอปอื่น (Display over other apps)** → เปิด (ให้ปุ่มลัดทำงานได้)
3. เปิดหน้าแอปล่าสุด (Recent) แล้ว **ล็อกการ์ด Termux** (กดเมนู/ปักหมุดที่การ์ด) กันถูกปิดตอนล้างแรม

## D. ตั้ง Chrome ให้เลือกที่เก็บไฟล์ / SD card

Chrome → ⋮ → **ตั้งค่า → ดาวน์โหลด** แล้วเปิด **Ask where to save files**
หลังจากนี้ทุกครั้งที่กดดาวน์โหลด จะมีหน้าต่างให้เลือกที่เก็บ (รวมถึง SD card)
หรือจะตั้ง "ตำแหน่งดาวน์โหลด" เป็น SD card ตายตัวก็ได้

## วิธีใช้ประจำวัน

1. กดไอคอน **YT2MP3** → Chrome เปิดหน้าเว็บให้เอง
2. วางลิงก์ → **แปลงเป็น MP3** → **ดาวน์โหลด** → เลือกที่เก็บ
3. เลิกใช้แล้วกด **YT2MP3-stop** (หรือปล่อยไว้ก็ได้ แต่จะกินแบตเล็กน้อย)

## แก้ปัญหา

- ดูบันทึกการทำงาน: `cat ~/yt2mp3.log`
- ดึงคลิปไม่ได้ / ขึ้น error จาก YouTube: `pip install -U yt-dlp` (YouTube เปลี่ยนระบบบ่อย)
- กดไอคอนแล้วหน้าเว็บไม่ขึ้น: เปิด Termux รัน `bash ~/.shortcuts/YT2MP3` ดูข้อความ error
- เปิดจากเครื่องอื่นในบ้าน: บนมือถือเซิร์ฟเวอร์เปิดเฉพาะเครื่องนี้เพื่อความปลอดภัย
